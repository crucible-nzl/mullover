# Social media · working folder

Everything for Counsel.day's organic social presence lives here. Reddit first;
other platforms get their own files when we start them.

## Files

| File | What it is |
|---|---|
| `persona.md` | The voice. Who posts, how James sounds, what we never say. Read this before writing anything. |
| `reddit-playbook.md` | The Reddit skill: what performs, account health, formats, timing, the per-post checklist, monitoring, what to do when a post is removed. |
| `reddit-subreddits.md` | The target map: which subreddits, what fits each, entry strategy, and the do-not-post list. |
| `posts/` | One file per post: draft, title options, engagement plan, outcome. The file IS the log entry · update it after the post runs. |

## The one rule

**Every post or comment that mentions Counsel.day discloses that James built
it.** No sockpuppets, no fake shopper framing, no vote rings, no alts, ever.

This is not just ethics housekeeping. It is the load-bearing wall of the
strategy: Reddit communities check post histories habitually, mods compare
notes, and unmasked astroturfing gets screenshotted and travels. Counsel.day
sells sealed privacy and honest process; the brand cannot survive being caught
faking grassroots opinions in communities of people making vulnerable
decisions. Disclosure also simply performs better there: "I built a thing
because we had this exact problem" is one of Reddit's best-loved genres.

If a post cannot work with disclosure, the post does not run.
